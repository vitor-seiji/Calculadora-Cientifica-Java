# Calculadora Científica em Java

Uma aplicação de calculadora científica desenvolvida em **Java**, projetada para realizar operações matemáticas básicas e avançadas de forma interativa e precisa.

---

## Funcionalidades

- **Operações Básicas:** Adição, subtração, multiplicação e divisão.
- **Funções Científicas:** 
  - Potenciação e radiciação ($x^y$, $\sqrt{x}$)
  - Funções trigonométricas (Seno, Cosseno, Tangente)
  - Logaritmos e exponenciais
